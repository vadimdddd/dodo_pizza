# Прототип системы детекции уборки столиков (Dodo Pizza)

## 1. Запуск проекта

Для работы с проектом выполните следующие шаги:

1.  **Скачайте видеофайлы:**
	https://disk.yandex.ru/i/NVbps-C1CbEq9Q - исходное видео для обработки
    https://disk.yandex.ru/i/t1TE2L7Jt_V3Dg - результат работы системы
2.  **Установите зависимости:**
    py -m pip install -r requirements.txt
3.  **Запустите скрипт:**
    py main.py --video video1.mp4

## 2. Структура проекта

В папке должны находиться следующие файлы и директории:
*   **`sample_with_human.jpg`**: Пример работы системы с человеком за столиком.
*   **`sample_without_human.jpg`**: Пример работы системы без человека за столиком.
*   **`main.py`**: Основной скрипт на Python.
*   **`requirements.txt`**: Список библиотек.
*   **`README.md`**: Эта инструкция.
*   **`video1.mp4`**: Входной файл с камеры для работы системы (скачивается вручную).
*   **`yolo26n.pt`**: Файл обученной модели (скачивается автоматически).
*   **`output.mp4`**: Результат работы скрипта (создается автоматически после работы системы).
